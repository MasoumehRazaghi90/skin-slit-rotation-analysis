# Skin Slit Rotation Analysis

This repository contains MATLAB code for simulating slit-rotation skin meshing patterns using GIBBON and FEBio.

The code generates a rectangular skin-like sheet with repeated slit patterns, rotates the slit layout, creates a finite element mesh, assigns material directions, runs the FEBio simulation, and post-processes the results.

The main purpose of this repository is to study how slit orientation affects the mechanical response of a skin-inspired meshing pattern.

---

## Important requirement: GIBBON

This code requires the GIBBON toolbox. Without GIBBON, the script will not run because it uses GIBBON functions for geometry processing, meshing, FEBio file creation, FEBio execution, and post-processing.

Please install GIBBON before running the code:

https://www.gibboncode.org/Installation/

The GIBBON installation page explains that users can download GIBBON using Git/GitHub or as a zip file, and then run the installation script `installGibbon.m` from the main GIBBON folder.

You also need:

- MATLAB
- FEBio
- GIBBON toolbox

After installing GIBBON, make sure it is added to the MATLAB path before running this script.

## Main code

The main MATLAB file in this repository is:

```text
slit_rotation_GOH.m
What the code does

The script performs the following steps:

Defines the material parameters for the GOH model.
Defines the size of the rectangular plate.
Creates repeated slit patterns in the plate.
Rotates the slit pattern by a selected angle.
Converts the 2D slit geometry into a mesh.
Extrudes the 2D mesh into a 3D finite element mesh.
Defines boundary conditions for tensile loading.
Defines fibre directions for perpendicular and parallel cases.
Builds the FEBio input file.
Runs the FEBio simulation.
Imports FEBio output files.
Plots deformation, force, stress, energy, damage, and displacement results.

Slit rotation angle

The slit orientation is controlled using:

rotationAngle = 90;

The intended options are:

rotationAngle = 0;
rotationAngle = 45;
rotationAngle = 90;

In the script:

0 degrees represents the perpendicular slit orientation.
45 degrees represents the diagonal slit orientation.
90 degrees represents the parallel slit orientation.

For the 45 degree case, each slit is rotated about its own centre.
For the 0 and 90 degree cases, the slit layout is rotated about the plate centre.


Mesh settings

The mesh density is controlled mainly by:

pointSpacing = 2.5;

Smaller values create a finer mesh, but the simulation becomes slower.

Examples:

pointSpacing = 3;     % coarser mesh
pointSpacing = 2.5;   % intermediate mesh
pointSpacing = 2;     % finer mesh

The code prints the number of nodes and elements after meshing. This can be used to compare different mesh densities.

Material model

The script uses a two-fibre GOH-type anisotropic material model.

The main material parameters are defined near the beginning of the script:

c_ini
k1_ini
k2_ini
kappa_ini
k_ini
gamma

The fibre directions are evaluated for two cases:

angles_deg = [0 90];

These represent perpendicular and parallel fibre directions relative to the loading direction.

Boundary conditions

The lower edge of the model is fixed, and the upper edge is displaced in the loading direction.

The prescribed displacement is controlled by:

displacementMagnitude = 60;
Output

The script can generate:

deformed mesh plots
stress plots
p90 stress plots
displacement plots
force versus stretch plots
area ratio plots
Poisson-type response plots
strain energy plots
damage plots and animations

Temporary FEBio input and output files are generated during the simulation.

Important note about file paths

The script may contain a local path such as:

savePath = 'C:\Sahar-GIBBON-codes\...';

Before running the code on another computer, change this path to a folder that exists on your own system.

A more portable option is to use:

defaultFolder = fileparts(mfilename('fullpath'));
savePath = fullfile(defaultFolder,'data','results');
How to run
Install GIBBON and FEBio.
Open MATLAB.
Add GIBBON to the MATLAB path.
Open this repository folder in MATLAB.
Run the main script:
slit_rotation_GOH
Notes

This repository is intended for computational biomechanics research involving skin-inspired slit meshing patterns and anisotropic material behaviour.

Large temporary FEBio output files are not included because they can be regenerated by running the MATLAB script.
